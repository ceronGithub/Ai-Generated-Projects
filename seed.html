Connect to Firebase

Open js/firebase/f_config.js in your code editor and paste your Firebase project credentials. You only need to do this once per project.

  1. Go to console.firebase.google.com and open your project.
  2. Click the ⚙ gear icon next to "Project Overview" → select Project settings.
  3. Scroll down to Your apps. If you haven't registered a web app yet, click the </> icon to add one.
  4. Copy the firebaseConfig object shown and paste it into js/firebase/f_config.js replacing the placeholder values.
// js/firebase/f_config.js — should look like this:const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "your-project.firebaseapp.com", projectId: "your-project", storageBucket: "your-project.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abc123" };

2

Authorize Your Local Domain

Firebase blocks sign-in from unknown domains by default. Since you're running this locally, you need to whitelist 127.0.0.1 (or localhost) in the Firebase console. Skipping this causes the "domain not authorized for OAuth" error.

  1. In the Firebase console, go to Authentication in the left sidebar.
  2. Click the Settings tab at the top.
  3. Scroll down to Authorized domains.
  4. Click Add domain and enter 127.0.0.1 — then click Add.
  5. Repeat and add localhost too if not already listed.
⚠️ Without this step, login will fail with a domain error even if your credentials are correct.
Click to unlock Step 3
3

Set the Owner Role in Firestore

This seeder checks that the logged-in user has role: "owner" in Firestore before allowing the seed to run. You need to create this document manually once — otherwise login will succeed but the seed button stays locked.

  1. In Firebase console, go to Authentication → Users tab.
  2. Find your owner account (e.g. owner@streetwiseph.com) and copy their User UID.
  3. Go to Firestore Database in the left sidebar.
  4. Navigate to (or create) the users collection.
  5. Click Add document — set the Document ID to the UID you copied (not the email).
  6. Add the fields below to that document and save.
// Firestore → users → {ownerUID} — fields to add:{ role: "owner" ← string email: "owner@streetwiseph.com" ← string (optional but helpful) }
💡 The Document ID must exactly match the Firebase Auth UID — not the email address.

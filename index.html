    Help & Guide

    Welcome to PDFExtract

    A cosmic-powered tool to extract, search, and export data from your PDF files — entirely in your browser. No files ever leave your device.

    01
    Upload PDFs

    Drag & drop or browse up to 2,000 PDF files at once.

    02
    Select Mode

    Choose how you want to extract — Multiple Keywords, Single Keyword, or Extract All.

    03
    Add Keywords

    Type the labels you want to find (e.g. "Invoice No. :", "Total Amount :").

    04
    Run & Export

    Hit Run Extraction, review results, then download as Excel.

    Extraction Modes

    🔑
    Multiple Keywords

    Search many keywords at once across all uploaded files. Results show each matched value per file and page. Best for extracting structured data from invoices, reports, or forms.

    🔍
    Single Keyword

    Search one keyword and use the extracted value to automatically rename your PDF files. Ideal for sorting batches of invoices by invoice number, date, or client name.

    📋
    Extract All

    Dumps all detected fields and text from every page of every uploaded PDF. No keywords needed. Also activates the AI Agent so you can ask questions about your documents.

    Keyword Formatting

    Keywords tell the extractor what label to find in the PDF. The value that follows the label is captured.

    Invoice No. :Spaced colon — matches "Invoice No. : 12345"
    Total Amount:Attached colon — matches "Total Amount:1,200.00"
    DateBare word — captures all dates on the page
    Zone :Toll column — extracts zone codes like NAIAX, SLEX
    Entry :Entry point column from toll transaction tables
    Exit :Exit point column from toll transaction tables
    E-SI No. :E-SI reference number from toll PDFs
    Ref No. :Transaction reference / IER number

    💡 Use Pick Option cards to match one of several possible values per keyword. Use Record Both to capture the first and second occurrence.

    ✦ AI Agent

    The AI Agent appears automatically after running Extract All. It reads the full text of all your PDFs and lets you ask questions in plain language.

    📋
    Summarize

    Get a concise summary of all extracted content across every file.

    💰
    Find Totals

    Ask it to list all monetary amounts, fees, and totals it found.

    🔍
    Any Question

    Ask anything — "What is the invoice number on page 2?", "Which file has the highest total?", "List all plate numbers found."

    The agent remembers your last 10 messages. Click ↺ to reset the conversation.

    Exporting Results

    All results can be downloaded as an Excel (.xlsx) file with one click.

    📊
    Multiple Keywords

    Each keyword gets its own column. Each file is a row. Multi-value results are comma-separated.

    🗂
    Extract All

    Each detected field label and value is exported with its filename and page number.

    🏷
    Single Keyword (Rename)

    Files are renamed using the extracted value. Download the renamed copies as a ZIP, or copy the rename map.

    Tips & Tricks

    • ✦ Drag & drop hundreds of PDFs at once — batch processing is fully supported.
    • ✦ Keywords are case-insensitive. "invoice no." and "INVOICE NO." both work.
    • ✦ Add a trailing space + colon (Label :) when the PDF uses spaced colons.
    • ✦ Use Extract All first on a new PDF type to discover what labels are available.
    • ✦ The AI Agent can calculate totals — ask "What is the sum of all toll fees?"
    • ✦ Click the 👁 eye icon on any uploaded file to preview it in the built-in PDF viewer.
    • ✦ Results can be individually removed with the ✕ button, or cleared all at once.
    • ✦ All processing is 100% local — no data ever leaves your browser.

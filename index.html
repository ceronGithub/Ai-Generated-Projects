Help & Documentation
Overview

Scrpd is an AI-powered web scraper that takes any URL you provide, fetches the page content, and uses a large language model to generate a clear, concise summary — all in a few seconds.

Summary

Every scrape request travels through this 6-step pipeline powered by n8n workflows running on a backend server.

Step by Step
  • 1You enter a URL — paste any publicly accessible web page address and click Scrape.
  • 2Request sent to n8n — the app sends your URL to an n8n webhook running on Render.com.
  • 3Page is fetched — n8n makes an HTTP GET request and retrieves the raw HTML of the page.
  • 4Text is extracted — a Code node strips all HTML tags, scripts, and noise — leaving only readable text (up to 12,000 characters).
  • 5AI summarizes it — the cleaned text is sent to Groq's free API running LLaMA 3.3 70B, which generates a human-readable summary.
  • 6Result displayed — the summary, word count, and domain are returned to your browser and shown on screen.

What Works Well ✅
▸News articles & blog posts — Clean text content scrapes and summarizes perfectly.
▸Documentation pages — Technical docs, READMEs, and wikis summarize very well.
▸Product pages — E-commerce and landing pages with readable text content.
▸Wikipedia & encyclopedias — Excellent results due to structured, clean content.
▸Research & academic pages — Abstracts and article pages summarize clearly.
Limitations ⚠️
▸First request may be slow (30–60s) — The free Render server spins down after inactivity. First request wakes it up. Subsequent requests are fast.
▸JavaScript-heavy sites — Single-page apps (React, Vue) that load content dynamically may return little text since n8n fetches raw HTML only.
▸Text limit of 12,000 characters — Only the first ~12,000 characters of extracted text are sent to the AI. Very long pages are truncated.
▸Login-required pages — Pages behind authentication (Gmail, Facebook, paywalled articles) cannot be scraped.
▸Bot-blocking sites — Some sites (Cloudflare-protected, LinkedIn, Twitter/X) actively block automated requests.
▸PDFs & images — The scraper reads HTML text only. PDFs, image-heavy pages, and videos won't produce meaningful summaries.
Performance & Costs

This app is 100% free to run using the current stack:

▸Netlify — Free hosting with 100GB bandwidth/month.
▸Render.com — Free tier for n8n (750 hrs/month, spins down after 15 min inactivity).
▸Groq API — Free tier with up to 30 requests/min on LLaMA 3.3 70B.
Tips for Best Results
  • 💡Use direct article URLs — e.g. site.com/article/title not just site.com
  • 💡If a page fails, wait 5 seconds and retry — the Render server may have been waking up from sleep.
  • 💡For paywalled content, try the Google cached version of the article instead.
  • 💡The AI summary covers main topic, key points, and notable details — it won't reproduce the full article.

    How to Use PDFExtract

    PDFExtract lets you search for specific keywords inside one or many PDF files and pull out the exact values next to those keywords — no manual reading required.

    01

    📄 Upload PDFs

    Drag and drop your PDF files into the upload zone, or click Browse Files. You can upload multiple files at once.

    02

    ⚙️ Choose a Mode

    Select Multiple Keywords, Single Keyword, Extract All, or Table Mode depending on what you need. See the Modes tab for details.

    03

    🔑 Enter Keywords

    Type the label that appears in your PDF (e.g. Account Name, Date, Total). See the Keywords tab for special keywords. Not needed for Extract All or Table Mode.

    04

    ▶ Run & Review

    Click Run Extraction. Results appear as cards below. Click the View button on any card to jump directly to that page in the PDF.

    05

    📥 Export to Excel

    Click Download to Excel to save all results as a spreadsheet. Choose Rows or Columns layout before exporting.

    🔑

    Multiple Keywords

    Finds values next to specific labels — great for invoices & forms where you need many fields at once. Each keyword produces its own result card per file. Not suited for large tables or transaction rows — use Table Mode instead when your data is structured in rows.

    Best for: invoices & forms
    🔍

    Single Keyword

    Focus on one keyword across all PDFs. Results are grouped per file and you can rename each PDF using the captured value. Use this when you need to find every occurrence of one specific field across many documents.

    Best for: bulk scanning & renaming
    📋

    Extract All

    Automatically detects and extracts all label–value pairs from every page of every PDF — no keyword input needed. Ideal for exploring an unfamiliar document or doing a full data dump.

    Best for: auto-detect & exploration
    🗂️

    Table Mode

    Designed for large tables — parses every row automatically and captures Tag, Zone, Entry, Exit & Toll Fee without any keywords. Purpose-built for SMC Skyway Transaction History Reports spanning many pages. Results are shown as individual transaction cards and can be exported to Excel.

    Best for: large transaction tables

    Keywords match the labels printed in your PDF. You can type them with or without a colon. A few keywords have special smart behaviour:

    Keyword What it extracts Example output
    📅 Date Every date value on the page (date part only, no time) 02/01/2026
    🕐 Time Every time value with exactly two colons (HH:MM:SS) 16:41:37
    🛣️ Zone Highway / zone codes from transaction rows NAIAX · SKYWAY
    🏢 Account Name Text value after the "Account Name" label National Grid Corp.
    💰 Total Numeric/currency value after "Total" Php 78,979.20
    🪪 TIN Tax ID number after "TIN" 006-977-514-000
    💡

    You can enter keywords in any case — date, Date, and DATE all work the same way.

    💡

    If a keyword has multiple values on the same page, a picker card appears so you can choose which value to keep before exporting.

    After running an extraction, click Download to Excel to save your results as an .xlsx file.

    📋 Rows Layout

    Each result is its own row. Best for reviewing individual hits or comparing many files side-by-side (e.g. batch of invoices).

    FileDateTotal
    invoice1.pdf02/0145.00
    invoice2.pdf02/0399.00

    📊 Columns Layout

    Each keyword becomes its own column. Results stack vertically per keyword. Best for single-document deep extraction or grouping by Tag Number in Table Mode.

    KeywordValuePage
    Date02/011
    Total45.001
    ⚠️

    You can rename PDF files before exporting — click the pencil icon next to any filename in the results to set a custom display name in the Excel output.

    🔍

    View PDF pages inline

    Every result card has a View button. Click it to open the PDF at the exact page where the value was found — no need to leave the app.

    🗑️

    Remove individual results

    Don't need a particular result card? Click the ✕ on any card to remove it before exporting. Only the remaining cards go into the Excel file.

    ✏️

    Edit extracted values inline

    Click directly on an extracted value in a result card to edit it before exporting. Useful for correcting OCR artefacts or reformatting data.

    📅

    Date vs Time keywords

    Use Date to get only the calendar date (e.g. 02/01/2026) and Time to get only the clock value (e.g. 16:41:37). They are independent and can both be added to the same extraction.

    🗂️

    Use Table Mode for large reports

    When your PDF contains rows of transaction data — like an SMC Skyway toll report — skip keywords entirely and use Table Mode. It reads every row automatically and gives you clean, structured cards ready to export.

    📁

    Batch multiple PDFs

    Upload many PDF files at once and run a single extraction. Every file is processed in one pass and all results are combined in the Excel export, labelled by filename.

    ↺

    Change mode mid-session

    Click ↺ Change Mode at any time to switch between modes without re-uploading your files.

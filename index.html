HOW TO USE — NORMAL MODE
  1. 1Upload your floor plan image by dragging it into the zone below or clicking to browse.
  2. 2Click INITIATE ANALYSIS — no API key needed, completely free.
  3. 3The AI Agent animation plays, but results come from a built-in residential template — not from reading your image.
  4. 4Room names, labels, and text on your floor plan are not read in this mode. Use results only for rough ballpark estimates.
  5. 5For image-specific analysis, switch to Advanced mode.
⚠ Important: Normal mode does NOT read text from your image. Labels like "Bedroom", "836 sq. ft.", or "1 Bathroom" on your floor plan are ignored — results are generated from standard templates only. Switch to Advanced mode for real AI image reading.
HOW TO USE — ADVANCED MODE
  1. 1Get a free API key from console.anthropic.com — new accounts get $5 free credits (~250 scans).
  2. 2Paste your key (starts with sk-ant-) into the API key field below.
  3. 3Upload your floor plan and click INITIATE ANALYSIS. Claude AI will actually read your image.
  4. 4The AI reads all text labels (e.g. "Bedroom", "836 sq. ft.", "1 Bathroom"), scale bars, room boundaries, and furniture symbols.
  5. 5Results include real per-room dimensions, confidence scores, architectural observations, and a scale note — ideal for accurate BOQ generation.
✓ Real AI reading: Claude reads every label, number, and room name directly from your floor plan image — just like a human would. Text like "836 sq. ft." is used as a known anchor to derive accurate room dimensions. Each scan costs ~₱1.00. Key is never stored.

HOW TO USE — STANDARD MODE
  1. 1Upload one or more floor plan images — multiple files supported.
  2. 2Click GENERATE BOQ ANALYSIS — no API key needed, completely free.
  3. 3Each image is processed in sequence. Results stack below — one full BOQ per image.
  4. 4Click any thumbnail to scroll to that image's BOQ. Edit unit rates by clicking blue values.
BOQ quantities are template-based — derived from standard residential concrete work proportions, not extracted from your specific image. For image-specific quantities, switch to AI-Powered mode.
HOW TO USE — AI-POWERED MODE
  1. 1Enter your Anthropic API key in Module 01 (Floor Plan Analyzer tab) — it will be used here automatically.
  2. 2Upload your floor plan images — multiple files supported.
  3. 3Click GENERATE BOQ ANALYSIS. Claude AI reads each image and generates tailored concrete work quantities.
  4. 4Each image produces a unique BOQ based on detected rooms, wall lengths, and slab areas from your actual plan.
  5. 5Edit unit rates by clicking any blue value. Export all BOQs to CSV with one click.

    How to Use PDFExtract

    PDFExtract is an all-in-one PDF toolkit that runs entirely in your browser. No uploads, no servers — your files never leave your device. Choose from 13 modes covering extraction, conversion, and PDF manipulation.

    01

    📄 Upload PDFs

    Drag and drop your PDF files into the upload zone, or click Browse Files. You can upload up to 2,000 files at once.

    02

    ⚙️ Choose a Mode

    Select any of the 13 extraction or PDF tool modes. Extraction modes need keywords; tool modes (Compress, Split, Merge, Convert, Enhance, Lock) run automatically.

    03

    🔑 Configure (if needed)

    For keyword modes — type your labels and press Enter. For Split PDF, set page ranges in Step 03.1. For Merge PDF, reorder files in Step 03.1. For Lock PDF, set passwords per file in Step 04.

    04

    ▶ Run & Review

    Click Run Extraction. A per-file progress list shows which file is being processed. Results appear as cards — remove unwanted ones with ✕ before exporting.

    05

    📥 Export or Download

    Download individual files or use Download All to get a ZIP. Keyword results can also be exported to Excel in Rows or Columns layout.

    PDFExtract has 7 extraction modes for reading and searching PDF text.

    🔑

    Multiple Keywords

    Search for many labels at once. Each keyword produces its own result card per file. Supports negative keywords (prefix !) to exclude results. Great for invoices and forms.

    Best for: invoices & forms
    🔍

    Single Keyword

    Focus on one keyword across all PDFs. Captured values can be used to batch-rename your PDF files automatically. Results are grouped per file.

    Best for: bulk scanning & renaming
    📋

    Extract All

    Automatically detects and extracts all label–value pairs from every page — no keywords needed. Detects Transaction History Reports and Sales Invoices and gives them specialised output.

    Best for: auto-detect & exploration
    🗂️

    Table Mode

    Purpose-built for SMC Skyway Transaction History Reports. Parses every transaction row — Tag, Plate, Ref No., Date, Zone, Entry, Exit, Toll Fee — and exports to Excel.

    Best for: SMC Skyway reports

    💡 OCR mode — in the Keywords section, toggle OCR: ON to automatically scan image-only or scanned PDF pages using Tesseract.js. Works with all keyword extraction modes.

    PDFExtract has 9 PDF tool modes that process your files without needing any keywords.

    🗜️

    Compress PDF

    Re-renders each page at reduced quality to shrink the file size. Download individually or all at once as a ZIP.

    Reduces file size
    ✨

    Enhance PDF

    Re-renders at 2.5× scale and 96% JPEG quality — noticeably sharper and clearer output, larger file size.

    Improves clarity
    ✂️

    Split PDF

    Split one PDF into multiple files. Choose Every N Pages for equal parts, or Custom Ranges (e.g. 1-3, 4-7, 8). Live preview shows output before you run.

    Divides pages
    🔗

    Merge PDF

    Combine multiple PDFs into one. Drag the ⠿ handle or use ↑↓ buttons in Step 03.1 to set the page order before merging.

    Combines files
    🔒

    Lock PDF

    Password-protect your PDFs with RC4-128 encryption. Enter a password (min 8 chars, mixed alphanumeric) per file in Step 04 before downloading.

    Adds password
    📊

    Convert to Excel

    Extracts all text from each PDF page and organises it into rows and columns in an .xlsx spreadsheet. One sheet per page.

    Outputs .xlsx
    📝

    Convert to Word

    Exports all PDF text into a .docx Word document. Each page is separated by a page break for clean editing.

    Outputs .docx
    📽️

    Convert to PPT

    Renders each PDF page as a full-slide image in a .pptx PowerPoint file. One slide per page at 144 dpi.

    Outputs .pptx
    🖼️

    Convert to JPG

    Renders each page as a high-resolution JPG image at 192 dpi. Multiple pages are bundled into a ZIP automatically.

    Outputs .jpg / .zip

    Keywords match the labels printed in your PDF. Type them with or without a colon. Several keywords have special smart behaviour:

    Keyword What it extracts Example output
    📅 Date Every date value on the page (date part only, no time) 02/01/2026
    🕐 Time Every time value with exactly two colons (HH:MM:SS) 16:41:37
    🛣️ Zone Highway / zone codes from transaction rows NAIAX · SKYWAY
    🏢 Account Name Text value after the "Account Name" label National Grid Corp.
    💰 Total Numeric/currency value after "Total" Php 78,979.20
    🪪 TIN Tax ID number after "TIN" 006-977-514-000
    🚫 !keyword Negative keyword — excludes results that contain this word !VAT filters out VAT rows
    💡

    Keywords are case-insensitive — date, Date, and DATE all work the same way.

    🔬

    OCR toggle — enable OCR in Step 03 to scan image-only pages using Tesseract.js. Requires an internet connection to load the OCR library on first use.

    If a keyword has multiple values on the same page, a picker card appears so you can choose which value to keep before exporting.

    Download All — available in Compress, Split, Merge, Convert, and Enhance modes. Downloads a ZIP containing all generated files.

    ✏️

    Rename PDFs — in Single Keyword mode, click ✏ Rename PDF to batch-rename all files using their captured values and download as a ZIP.

    🔒

    Lock PDF — enter a password (minimum 8 characters, must contain letters and numbers) per file, then click 🔒 Lock & Download.

    🔍

    View PDF pages inline

    Result cards in Split PDF mode have a View button — click it to preview the generated file directly in the built-in PDF viewer without downloading.

    🚫

    Negative keywords

    Prefix any keyword with ! to exclude results containing that word. Example: add Total and !VAT to capture totals but skip any VAT rows.

    🔬

    OCR for scanned PDFs

    If your PDF is a scan or image-only document, toggle OCR: ON in Step 03. Tesseract.js will automatically detect pages with no selectable text and run OCR on them.

    🕐

    Session restore

    Your last mode and keywords are saved automatically. On your next visit, a banner appears offering to restore your previous session with one click.

    🔗

    Reorder before merging

    In Merge PDF mode, a Step 03.1 panel shows all uploaded files. Drag the ⠿ handle or use ↑↓ arrows to set the exact order before merging.

    ✂️

    Live split preview

    In Split PDF mode, as you type a page count or range, a live preview updates instantly — e.g. "23 pages → 5 files of up to 5 pages each" — before you run.

    📁

    Batch up to 2,000 files

    Upload many PDF files at once and run a single extraction. A per-file progress list in Step 04 shows exactly which file is being processed in real time.

    ↺

    Change mode anytime

    Click ↺ Change Mode at any time to switch modes without re-uploading. Steps 03 and 04 animate away cleanly and reset for the new mode.

    🗂️

    Table Mode for SMC reports

    When your PDF is an SMC Skyway Transaction History Report, skip keywords entirely. Table Mode reads every row automatically and exports all fields to Excel.

Overview
How It Works

MailVault is a Google Apps Script project that lives inside your own Google Account. It reads your Gmail on request, lets you review and manage the results, then downloads the export directly to your device.

🏠
Stays in Google
Runs on Google's servers inside your account. Never touches outside infrastructure.
📖
Read-Only Gmail
Can only read emails. Cannot send, delete, or modify anything.
💾
Local Downloads
CSV, PDF, and Text files download directly to your device — not to Drive.
✏️
Edit Before Export
View, edit, or remove emails from the list before downloading.
🔀
Sort & Filter
Sort by newest, oldest, subject, or sender before exporting.
👁️
Open Source
Full source code below — every line is readable and auditable.
🔒
Your data never leaves Google
The script runs server-side inside your Google Account. Emails flow from Gmail to your browser to your local device. No third-party servers, no analytics, no data collection of any kind.
⚠️
Each person needs their own deployment
Do NOT share your Web App URL with others — the script runs as your Google account and would expose your Gmail. Each person must follow this setup guide to deploy their own private copy.
Installation
One-Time Setup

Takes about 5 minutes. After setup, just open your Web App URL anytime to export emails — no need to return here.

Step
01
Go to Google Apps Script

Open your browser and navigate to script.google.com

Sign in with the Gmail account whose emails you want to export.

Step
02
Create a New Project

Click + New project in the top left.

Click "Untitled project" at the top → type MailVault → click Rename.

Step
03
Paste Code.gs

The editor opens with Code.gs by default. Click inside it → Ctrl+A → Delete to clear it.

Copy the full Code.gs source below, paste it in, press Ctrl+S.

Step
04
Add the index.html File

Hover over "Files" in the left sidebar → click the + icon → choose HTML.

Name it exactly index (no .html extension) → press Enter.

Delete the placeholder → paste the full index.html source below → Ctrl+S.

Step
05
Deploy as a Web App

Click the blue Deploy button (top right) → New deployment.

Click the ⚙️ gear icon → select Web app.

Set: Execute as: Me · Who has access: Only myself

Click Deploy → Authorize access → choose your account → Allow.

You may need to click "Advanced" → "Go to MailVault (unsafe)" first.

Copy the Web App URL — bookmark it!

Step
06
Authorize Drive Permissions

In Apps Script editor, click the function dropdown (shows "doGet") → select exportToPdfFiles.

Wait — there is no such function now. Skip this step. All exports now happen in the browser.

✓ You're done! Open your Web App URL to start exporting.

💡
Updating the app
After editing Code.gs or index.html, go to Deploy → Manage deployments → ✏️ pencil → Version: New version → Deploy. Your URL stays the same.
User Guide
App Features

Open your Web App URL in any browser. The interface has three steps.

Step 01 — Date Range

Set a From and To date. Your Gmail address is automatically detected and shown in the header — no manual entry needed. For a single day, set both dates to the same date.

Step 02 — Fetch & Manage

Click Fetch Emails to search Gmail. Results appear in a table with four actions per email:

👁 View

Opens a modal with all email fields: Subject, From, To, CC, Date, Labels, Body, Read/Starred status.

✏️ Edit

Opens an editable form. Change Subject, From, To, CC, Labels, Body. Edits only affect the export — Gmail is untouched.

🗑 Remove

Removes that email from the export list. Does not delete it from Gmail.

🔀 Sort

Sort by Newest, Oldest, Subject A–Z, or From A–Z using the buttons above the table.

Step 03 — Export to Device

Choose a format and click Download. Files save directly to your device's Downloads folder:

📊
CSV
Opens in Excel or Google Sheets. Includes a summary section.
📕
PDF
Print-ready. A window opens → choose Save as PDF in the print dialog.
📄
Text
Plain .txt file. One email per block with ASCII borders.
Uninstall
Remove MailVault from Your Account

Follow all three steps to completely remove MailVault. Each step removes a different component.

A
Revoke Gmail & Drive Permissions

This stops the script from accessing your Gmail. After this, even if someone has the URL, it cannot read any data.

myaccount.google.com/permissions

1. Go to the URL above and sign in.
2. Find MailVault or the Apps Script project in the list.
3. Click it → click Remove Access → confirm.

B
Delete the Apps Script Project

This deletes the script code and permanently invalidates the Web App URL.

script.google.com

1. Go to the URL above.
2. Find your MailVault project in the list.
3. Click the ⋮ three-dot menu → click Remove → confirm.

C
Delete Exported Files (Optional)

Any CSV, PDF, or TXT files you downloaded live on your own device. Delete them from your Downloads folder manually if needed. If you ever ran the old version that saved to Google Drive, search Drive for "MailVault" and delete those files too.

✅
Full Removal Checklist
✓ Revoked permissions at myaccount.google.com/permissions
✓ Deleted the project at script.google.com
✓ Deleted any exported files from your device / Google Drive

After all three steps, MailVault has zero presence in your Google account.
Help
Troubleshooting

"Script function not found: doGet"

Code.gs was deployed before being saved. Go to Apps Script, re-paste Code.gs, press Ctrl+S, then create a new deployment version.

"No emails found" for a date you know has emails

Widen the date range by one day in each direction. Gmail's after/before date search can be offset by your timezone.

"Script timeout" error

Google Apps Script has a 6-minute execution limit. Use a shorter date range. Google Sheets export (old version) handles large batches faster.

Export button is greyed out

You need to fetch emails first. Click Fetch Emails and wait for the preview table before the Export button becomes active.

function initCode(){
  const gsPre  = document.getElementById('gsDisplay');
  const htmlPre = document.getElementById('htmlDisplay');
  const escHtml = s => s.replace(/&/g,'&').replace(//g,'>');
  gsPre.textContent  = CODE_GS;

function copyCode(which){
  const code = which === 'gs' ? CODE_GS : CODE_HTML;
  const btnId = which === 'gs' ? 'copyGsBtn' : 'copyHtmlBtn';
  const btn = document.getElementById(btnId);
  navigator.clipboard.writeText(code).then(()=>{
    btn.innerHTML = ' Copied!';
    btn.classList.add('copied');
    showToast(which === 'gs' ? 'Code.gs copied to clipboard!' : 'index.html copied to clipboard!');
    setTimeout(()=>{ btn.innerHTML = ' Copy Code'; btn.classList.remove('copied'); }, 2500);
  }).catch(()=>{
    // Fallback: select all text in the pre
    const pre = document.getElementById(which === 'gs' ? 'gsDisplay' : 'htmlDisplay');
    const range = document.createRange(); range.selectNodeContents(pre);
    const sel = window.getSelection(); sel.removeAllRanges(); sel.addRange(range);
    showToast('Text selected — press Ctrl+C to copy');
  });
}

function showToast(msg){
  const t = document.getElementById('toast');
  t.textContent = msg;
  t.style.transform = 'translateY(0)';
  t.style.opacity = '1';
  clearTimeout(t._t);
  t._t = setTimeout(()=>{ t.style.transform = 'translateY(80px)'; t.style.opacity = '0'; }, 2800);
}

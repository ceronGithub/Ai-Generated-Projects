    How to Use PDFExtract

    Welcome to PDFExtract

    Upload PDF files, choose an extraction mode, and run. All processing happens locally in your browser — no files are ever uploaded to a server.

    Extraction Modes

    Multiple Keywords — search several keywords across all files at once.

    Single Keyword — search one keyword and optionally rename the PDFs by the captured value.

    Extract All — dump all detected label:value fields from every page.

    Table Mode — extract structured transaction rows from SMC Skyway Transaction History Reports. Captures Tag Number, Plate, Ref No., Date, Time, E-SI No., Zone, Entry, Exit and Toll Fee as individual cards.

    Keyword Formats

    Keywords can include a trailing colon (TIN:), a spaced colon (Date :), or be bare (Total). The engine auto-detects the format.

    Tips

    Drag and drop up to 2,000 PDFs at once. Use Table Mode for SMC Skyway toll transaction reports to get perfectly structured results without typing any keywords.
